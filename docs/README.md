# hersaid documentation

The [README](../README.md) has the install snippet, a quick start and a summary
of the safety model. These pages hold the full reference.

- [install.md](install.md): the three install routes in full.
- [credentials.md](credentials.md): the Slack apps and their scopes,
  `hersaid-setup`, where things live, and the environment variables.
- [usage.md](usage.md): every `hear`, `sez` and `tap` command and flag, with
  examples, and the full list of limitations.
- [safety-model.md](safety-model.md): what each command can and cannot do, and
  why.
- [audit-log.md](audit-log.md): the record `sez` and `tap` keep of every
  attempt, field by field, and how to query it.
